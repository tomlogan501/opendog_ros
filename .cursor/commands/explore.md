# Explore Command —

## 🎯 Purpose

Analyze requirements and existing codebase to understand the problem domain.

## 🚀 Usage

```bash
/explore [target]
```

## 📋 What it does

1. Analyze requirements and constraints
2. Explore existing codebase patterns
3. Identify dependencies and interfaces
4. Generate a domain understanding report (code-free summary)
5. Create an initial TODO list aligned with workflows (restructure docs, simplify, readiness)

## 📤 Output

- `EXPLORATION_REPORT.md` - Domain analysis and requirements
- `TODO.md` - Initial task breakdown
- `docs/requirements/` - Extracted requirements (no code)

## 🔍 Examples

```bash
/explore "fire detection system"
/explore existing_package
/explore requirements.md
```

## 🎯 Integration

- Updates TODO.md with progress
- Validates prerequisites
- Generates next steps
- Updates system status

## 📖 Quality Gates

- Requirements understood
- Constraints identified
- Dependencies mapped
- Domain model created
