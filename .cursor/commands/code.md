# Code Command —

## 🎯 Purpose

Implement the planned solution following Clean Architecture.

## 🚀 Usage

```bash
/code [package_name] [phase]
```

## 📋 Phases

- `setup` - Package structure and interfaces
- `core` - Business logic
- `ros2` - Interface layer
- `tests` - Tests
- `docs` - Documentation updates (no code in docs)

## 📋 What it does

1. Create or align structure with clean boundaries
2. Implement or simplify business logic
3. Create or refine interface layer
4. Implement tests and validation for readiness
5. Update documentation and status (code-free)

## 📤 Output

- Package structure with Clean Architecture
- Business logic implementation
- ROS2 interface layer
- Test implementations
- Updated documentation

## 🔍 Examples

```bash
/code gripper_control setup
/code gripper_control core
/code gripper_control ros2
/code gripper_control tests
/code gripper_control docs
```

## 🎯 Integration

- Updates TODO.md with progress
- Validates prerequisites
- Generates next steps
- Updates system status

## 📖 Quality Gates

- Implementation complete
- Tests written
- Documentation updated
- Code follows standards
