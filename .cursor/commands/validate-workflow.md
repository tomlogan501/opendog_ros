# Validate Workflow Command —

## 🎯 Purpose

Validate workflow compliance and task completion.

## 🚀 Usage

```bash
/validate-workflow [project_name]
```

## 📋 What it validates (code-free)

- All workflow phases completed (Explore → Plan → Code → Test → Iterate)
- Quality gates passed (docs, architecture, tests, readiness)
- Task dependencies resolved
- Documentation up to date and concise
- Tests and validation steps implemented

## 📋 Workflow Phases

- **Explore**: Requirements validated, constraints identified
- **Plan**: Architecture validated, interfaces defined
- **Code**: Implementation validated, tests written
- **Test**: Coverage validated, performance verified
- **Iterate**: Optimizations validated, documentation updated

## 📤 Output

- Workflow compliance report
- Phase completion status
- Quality gate results
- Recommendations for improvement

## 🔍 Examples

```bash
/validate-workflow fire_detection
/validate-workflow gripper_control
/validate-workflow navigation_system
```

## 🎯 Integration

- Updates TODO.md with progress
- Validates prerequisites
- Generates next steps
- Updates system status

## 📖 Quality Gates

- All phases completed
- Quality gates passed
- Dependencies resolved
- Documentation updated
- Tests implemented
