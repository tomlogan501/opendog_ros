# Status Command —

## 🎯 Purpose

Display current project status and progress.

## 🚀 Usage

```bash
/status
```

## 📋 What it does

1. Read TODO.md and docs/SYSTEM_STATUS.md
2. Calculate progress metrics
3. Identify current phase and workflow alignment
4. Show blockers and dependencies
5. Display next milestones and readiness gaps

## 📤 Output

- Project status overview
- Progress metrics
- Current phase
- Blockers and dependencies
- Next milestones

## 🔍 Examples

```bash
/status
```

## 🎯 Integration

- Reads TODO.md
- Validates task structure
- Generates summaries
- Updates metrics

## 📖 Quality Gates

- Status calculated correctly
- Progress tracked accurately
- Blockers identified
- Milestones displayed
