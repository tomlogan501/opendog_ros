# Iterate Command —

## 🎯 Purpose

Refine and optimize based on test results.

## 🚀 Usage

```bash
/iterate [package_name] [focus]
```

## 📋 Focus Areas

- `performance` - Optimize performance
- `architecture` - Refactor architecture
- `tests` - Improve test coverage
- `docs` - Update documentation

## 📋 What it does

1. Analyzes test results
2. Identifies improvement areas
3. Implements optimizations
4. Re-runs validation
5. Updates documentation

## 📤 Output

- Optimized implementation
- Improved test coverage
- Updated documentation
- Performance improvements

## 🔍 Examples

```bash
/iterate gripper_control performance
/iterate gripper_control architecture
/iterate gripper_control tests
/iterate gripper_control docs
```

## 🎯 Integration

- Updates TODO.md with progress
- Validates prerequisites
- Generates next steps
- Updates system status

## 📖 Quality Gates

- Optimizations applied
- Documentation updated
- Performance improved
- System validated
