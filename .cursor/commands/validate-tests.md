# Validate Tests Command —

## 🎯 Purpose

Validate test coverage and quality.

## 🚀 Usage

```bash
/validate-tests [package_name]
```

## 📋 What it validates

- Unit test coverage > 80%
- Integration tests implemented
- E2E tests cover main scenarios
- Test quality and maintainability
- Performance test baselines

## 📋 Test Types

- **Unit Tests**: Business logic in isolation
- **Integration Tests**: ROS2 interface testing
- **E2E Tests**: Complete system behavior
- **Performance Tests**: Performance baselines

## 📤 Output

- Test coverage report
- Test quality analysis
- Performance metrics
- Recommendations for improvement

## 🔍 Examples

```bash
/validate-tests pump_control
/validate-tests turret_control
/validate-tests gripper_control
```

## 🎯 Integration

- Updates TODO.md with progress
- Validates prerequisites
- Generates next steps
- Updates system status

- Integration tests implemented
